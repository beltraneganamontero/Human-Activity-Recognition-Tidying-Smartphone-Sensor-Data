# Getting and Cleaning Data — Human Activity Recognition Project

## Project objective

This repository contains a reproducible R workflow for the **Getting and Cleaning Data** course project. It processes the UCI Human Activity Recognition (HAR) smartphone dataset into a tidy table containing the **average of each selected mean or standard-deviation sensor measurement for every subject and activity**.

## Repository contents

| File | Purpose |
| --- | --- |
| `run_analysis.R` | Main R script implementing all five assignment requirements |
| `CodeBook.md` | Complete description of source data, transformations, all 68 output variables and measurement units |
| `tidy_data.txt` | Final tab-separated tidy dataset; **generated by running the script** (180 rows × 68 columns) |
| `.gitignore` | Prevents accidental addition of bulky raw data / downloaded archives |

The assignment asks for **one script**, named exactly `run_analysis.R` at the repository root. There are **no third-party R package dependencies**.

## Input data

Download the UCI HAR data from the [Coursera archive](https://d396qusza40orc.cloudfront.net/getdata%2Fprojectfiles%2FUCI%20HAR%20Dataset.zip). The `UCI HAR Dataset` directory contains:

- `features.txt` — 561 feature names and their numeric identifiers.
- `activity_labels.txt` — mapping between numeric activity codes and six meaningful names.
- `train/X_train.txt`, `train/y_train.txt`, `train/subject_train.txt`.
- `test/X_test.txt`, `test/y_test.txt`, `test/subject_test.txt`.

The raw inertial time-series in the `Inertial Signals` subdirectories are not used: the assignment concerns the **561 calculated feature columns** in `X_train.txt` and `X_test.txt`.

## How to reproduce in RStudio

1. Create or open an RStudio project in the directory containing `run_analysis.R`.
2. If your computer can reach the Coursera archive, you may run the script without manually downloading anything: it downloads and extracts the dataset if necessary.
3. If the download fails, download the ZIP using your browser, extract it, and place the resulting folder named **`UCI HAR Dataset`** alongside `run_analysis.R`.
4. Check the current directory with `getwd()`; if necessary, set the working directory to the project folder.
5. Run:

   ```r
   source("run_analysis.R")
   ```

6. Check the output:

   ```r
   tidy <- read.table("tidy_data.txt", header = TRUE, sep = "\t")
   dim(tidy)                       # 180 68
   length(unique(tidy$Subject))    # 30
   length(unique(tidy$Activity))   # 6
   head(tidy[, 1:6])
   ```

The script writes `tidy_data.txt` to the current working directory. Include the **generated** text file when publishing the repository, and upload the same file to the Coursera file-upload field.

## Analysis details and assignment requirements

**1. Merge the training and test sets.** Read the X sensor-feature matrices, the numeric activity labels (y) and subject identifiers for both partitions, preserving row alignment, and append them. Combined observations: **7,352 + 2,947 = 10,299**.

**2. Keep the mean and standard-deviation measurements.** Use the explicit pattern `-(mean|std)\(\)` against `features.txt`. This selects 66 original features, excluding `meanFreq()` and angles that merely mention `mean` elsewhere in the name.

**3. Replace numeric activity codes.** Match activities to their descriptive labels: `WALKING`, `WALKING_UPSTAIRS`, `WALKING_DOWNSTAIRS`, `SITTING`, `STANDING`, and `LAYING`.

**4. Make column names descriptive.** Expand abbreviations (`Acc`, `Gyro`, `Mag`, etc.), label the time/frequency domains, and remove punctuation. See `CodeBook.md` for the full mapping.

**5. Create an independent tidy summary.** Group by subject and activity, then calculate the mean of each of the 66 measurements. The result contains **30 subjects × 6 activities = 180 observations** and **68 variables** (2 identifiers + 66 numerical measures).

Each final row represents **one subject/activity group**; each measurement column contains **one normalized numeric summary**. No mixed types are stored in a measurement column.
